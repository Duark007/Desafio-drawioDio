# Desafio DIO - Arquitetura de Integração AWS com Java & Spring Boot

Este repositório contém a documentação técnica e o código-fonte referente ao desafio de arquitetura da **DIO (Digital Innovation One)**. O projeto ilustra um ecossistema corporativo na nuvem AWS, demonstrando a coexistência de dois padrões arquiteturais distintos para solucionar diferentes problemas de negócio utilizando **Java com Spring Boot**: uma abordagem *Serverless* e uma infraestrutura tradicional baseada em instâncias computacionais (*IaaS*).
